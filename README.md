# XOrder Summary

Order summary component built for the Crio.Do XOrder Summary buildout.

**Live site:** _see the Vercel deployment linked in this repo's About section_

## Features

- Responsive layout with separate desktop and mobile background patterns (breakpoint at 450px)
- Hover states on the Change link, the Proceed to Payment button and the Cancel Order button
- Red Hat Display font from Google Fonts

## Built with

- Semantic HTML5
- CSS custom properties and Flexbox
- Deployed on Vercel
